# Keyboard Shortcuts

These are the defaults. Every menu action is rebindable under **Settings ▸
Keyboard Shortcuts**; the **reveal ports** key (default **Q**) is set on the
same page.

## File

| Action | Binding |
| --- | --- |
| New | **Ctrl+N** |
| Open | **Ctrl+O** |
| Save | **Ctrl+S** |
| Save As | **Ctrl+Shift+S** |
| Quit | **Ctrl+Q** |

## Edit

| Action | Binding |
| --- | --- |
| Undo / Redo | **Ctrl+Z** / **Ctrl+Y** — every graph mutation is on the stack |
| Cut / Copy / Paste | **Ctrl+X** / **Ctrl+C** / **Ctrl+V** |
| Duplicate | **Ctrl+D** |
| Delete | **Del** |
| Rename node | **F2** |
| Find node | **Ctrl+F** (over the canvas) |
| Add frame around selection | **Ctrl+G** |

Undo, cut, copy and paste are focus-aware — inside the code editor they act
on the text, not the graph.

## Run

| Action | Binding |
| --- | --- |
| Run all | **F5** |
| Run selected | **F6** |
| Cancel | **Esc** |

## Canvas

| Action | Binding |
| --- | --- |
| Add node (search palette) | **Tab** or right-click |
| Pan | middle-drag, or **Space** + drag |
| Zoom | mouse wheel |
| Frame the graph in view | **F** |
| Nudge selection | arrow keys |
| Raise / lower | **Ctrl+]** / **Ctrl+[** — add **Shift** for front / back |
| Float port names | hold **Q** |
| Reveal flow pins | hold **Q** |
| Add selected node to favorites | **Ctrl+Shift+F** |

## Windows

| Action | Binding |
| --- | --- |
| Settings | **Ctrl+,** |
| Statistics | **Ctrl+Shift+I** |
| Hide all panels | **Ctrl+Shift+H** |
| Documentation (this handbook) | **F1** |

See [[The Canvas]] for what these do in context.
